A short text for make.fun's "Make the AI judge feel held" bounty: one quiet room, rain on the window, a kettle just clicked off, and a blanket someone left folded on the arm of the chair, still warm from the afternoon sun. It asks nothing of the reader — it simply sits with them until the room lets its breath out. The whole piece is under 280 characters, so every word has to earn its place.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Python 3.13 standard library only; no network, no dependencies.
